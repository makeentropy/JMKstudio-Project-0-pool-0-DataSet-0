# JMK-Dimension Studio

多维因果与量子拓扑科研IDE插件

## 🌌 系统架构

该系统分为四个核心维度层：

1. **观测层** - 科研维度空间透视建模引擎 (Vue.js + Three.js)
2. **节律层** - 事件控制框架与Karma因果节律控制器
3. **基底内核层** - base_XOR_boost-kernel
4. **奇点内存层** - 量子奇点维度空间

## 📦 安装依赖

```bash
npm install
```

## 🚀 运行项目

```bash
npm run dev      # 启动开发服务器
npm run build    # 构建生产版本
npm run preview  # 预览生产构建
```

## 🧬 核心功能

### 1. 量子奇点 (QuantumSingularity)
- 以圆周率 π 作为 JMKmap 基底常数
- 实现维度空间量化为弦
- 运行奇点算法

### 2. 因果节律控制 (KarmaRhythmController)
- DNA 式配置文件解析
- 事件节律控制
- 平行空间数据块分发
- 时间因果增量管理

### 3. 维度空间管理 (DimensionManager)
- 空间密码加密
- 数据隐写术
- 拓扑数据检索

## 🎨 可视化特性

- 3D 螺旋粒子系统可视化
- 熵值颜色编码 (低熵冷色调，高熵暖色调)
- 实时事件日志与平行空间追踪
- 交互式控制面板

## 📊 技术栈

- **前端框架**: Vue 3
- **3D 渲染**: Three.js
- **构建工具**: Vite
- **开发语言**: JavaScript
