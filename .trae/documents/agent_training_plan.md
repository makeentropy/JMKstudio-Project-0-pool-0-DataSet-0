# Agent 训练数据集收集与训练计划

## 1. 需求分析
用户需要：
- 收集 agent 历史数据
- 分析并生成预训练数据集
- 训练 agent job 智能体

## 2. 数据来源
- 豆包URL: https://www.doubao.com/thread/a675c7aea46f3
- 数据内容：
  - 基础量子拓扑概念：维度空间、量子波函数奇点的技术实现与金融映射
  - 金融数据三大分支：货币数据学、交易数据学、经济数据学
  - 资金管理工具：资金工具链、资金汲取向量

## 3. 项目现状
当前工作区是数据积攒池仓库 JMKstudio-Project-0-pool-0-DataSet-0

## 4. 实施步骤

### 阶段一：数据收集模块
1. 创建数据收集工具脚本
2. 实现网页内容抓取功能（支持豆包等平台）
3. 创建数据存储结构

### 阶段二：数据集处理模块
1. 数据清洗与预处理
2. 数据格式标准化
3. 数据集版本管理

### 阶段三：Agent 训练模块
1. 选择训练框架
2. 实现训练流程
3. 模型评估与优化

## 5. 文件结构规划

```
/workspace/
├── data/
│   ├── raw/              # 原始数据
│   ├── processed/        # 处理后的数据
│   └── datasets/         # 最终数据集
├── src/
│   ├── collector/        # 数据收集模块
│   ├── processor/        # 数据处理模块
│   └── trainer/          # 训练模块
├── scripts/              # 工具脚本
└── README.md
```

## 6. 技术栈建议
- 数据收集: Python + requests/BeautifulSoup/playwright
- 数据处理: pandas, numpy
- 训练框架: 根据需求选择（Hugging Face, PyTorch等）

## 7. 风险与注意事项
- 豆包页面可能有反爬虫机制
- 数据格式需要标准化
- 训练需要合理的计算资源
