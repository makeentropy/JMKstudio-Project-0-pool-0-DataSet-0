# 神誓工具链 (Oath Toolchain) - Product Requirement Document

## Overview
- **Summary**: 构建一个开源的密码学安全工具链项目——"神誓工具链"（Oath Toolchain），以KARMACA空间字典模型为核心，集成乾坤加密引擎、NLP密钥生成、奇点验证、几何证据、维度隐写、Karma数据标签等模块，提供可组合、可扩展的密码学安全工具集。
- **Purpose**: 为数据安全、隐私保护、加密认证等场景提供一套完整的开源工具链，支持从密钥生成、数据加密、身份认证到完整性证明的全流程安全保障。
- **Target Users**: 安全研究人员、密码学爱好者、开发者、数据保护工程师

## Goals
- 构建模块化、可扩展的神誓工具链架构
- 实现KARMACA空间字典模型作为核心加密原语
- 开发乾坤程序（Qiankun）作为统一加密引擎
- 提供NLPTCmodel自然语言密钥生成工具
- 实现质能质量子奇点算法验证器
- 构建几何证据加密与零知识证明模块
- 实现维度空间隐写与XOR隐写工具
- 建立Karma数据标签系统与数据集池管理
- 支持CLI、Python API、REST API三种调用方式
- 提供完整的文档、示例和测试用例

## Non-Goals (Out of Scope)
- 不实现真实的量子计算（均为经典计算模拟）
- 不提供真实的政府/军事认证法律效力
- 不涉及硬件安全模块（HSM）的物理实现
- 不承诺达到军事级安全标准（仅供研究学习）
- 不包含真实的FBI/CIA系统对接

## Background & Context
现有AI LLM Agent爬虫系统中的安全模块需要从架构层面重构，打造一个独立的、开源的神誓工具链项目。项目以"神誓"为核心理念，将密码学算法、数学证明、空间几何等概念融合，形成一套独特的安全工具生态。

## System Architecture

### 整体架构分层
```
┌─────────────────────────────────────────────────────────┐
│                   接口层 (Interface Layer)               │
│   CLI工具  │  Python API  │  REST API  │  GUI界面       │
├─────────────────────────────────────────────────────────┤
│                   编排层 (Orchestration Layer)           │
│   乾坤程序 (Qiankun) - 统一加密流程编排引擎              │
├─────────────────────────────────────────────────────────┤
│                   工具层 (Tools Layer)                   │
│  ┌─────────┐ ┌──────────┐ ┌─────────┐ ┌─────────────┐ │
│  │ KARMACA │ │ NLPTCmodel│ │ 奇点验证 │ │ 几何证据加密 │ │
│  └─────────┘ └──────────┘ └─────────┘ └─────────────┘ │
│  ┌─────────┐ ┌──────────┐ ┌─────────┐ ┌─────────────┐ │
│  │ 维度隐写 │ │ XOR隐写  │ │ CA证书  │ │ Karma标签   │ │
│  └─────────┘ └──────────┘ └─────────┘ └─────────────┘ │
├─────────────────────────────────────────────────────────┤
│                   核心层 (Core Layer)                    │
│   空间数学库 │ 密码学原语 │ 数据结构 │ 工具函数          │
└─────────────────────────────────────────────────────────┘
```

### 核心设计原则
1. **模块化**: 每个工具独立封装，可单独使用也可组合
2. **可扩展**: 插件化架构，支持动态添加新工具
3. **一致性**: 统一的API设计和错误处理规范
4. **可验证**: 所有算法提供数学证明和测试用例
5. **开源性**: 完全开源，社区驱动开发

## Functional Requirements

### FR-1: 神誓工具链核心架构
系统应提供模块化的工具链架构，支持工具注册、发现和组合调用。
- 工具注册与发现机制
- 统一的工具接口规范
- 工具链组合编排能力
- 插件化扩展支持
- 配置管理系统

### FR-2: KARMACA空间字典模型
实现基于N维空间的字典加密模型，作为工具链的核心加密原语。
- N维空间字典构建与管理
- 空间坐标到密钥的映射算法
- 空间维度隐写（数据嵌入高维空间）
- 空间字典动态扩展与压缩
- 空间几何运算库

### FR-3: 乾坤程序（Qiankun）统一加密引擎
提供统一的加密流程编排引擎，支持多种加密方案组合。
- 对称/非对称混合加密流程
- 多级加密链式处理
- 加密方案模板管理
- 加密流程可视化配置
- 加密审计日志

### FR-4: NLPTCmodel自然语言密钥生成
基于自然语言文本生成加密密钥。
- 文本语义特征提取引擎
- 多语言支持（中/英/日等）
- 密钥强度评估与优化
- 密钥派生函数(KDF)集成
- 口令扩展算法

### FR-5: 质能质量子奇点验证器
基于质能质量子奇点模型的密钥和数据验证。
- 数据质能计算模型
- 奇点检测算法集
- 密钥奇点特征提取
- 验证报告生成
- 快速验证模式

### FR-6: 几何证据加密
提供基于几何数学的完整性证明和加密机制。
- 几何哈希函数族
- 几何证明生成与验证
- Merkle树几何证明
- 零知识证明基础框架
- 可验证随机函数(VRF)

### FR-7: 维度空间隐写与XOR隐写
实现多层次数据隐藏技术。
- XOR隐加密算法
- 证书隐写（X.509扩展字段）
- 维度空间隐写（高维坐标嵌入）
- 图像/文本载体隐写
- 隐写容量与安全性分析

### FR-8: JMKstudio CA证书体系
扩展的多级CA证书系统。
- JMKstudio根CA管理
- FBI/CIA中间CA证书链
- 战舰证书/科学证书类型
- 证书几何证据扩展
- 证书生命周期管理

### FR-9: Karma数据标签系统
数据集的karma标签管理和认证。
- datafor/datefor/datatag标签格式
- GPGCA/JMKCA标签签名
- base64标签编解码
- 数据集池标签索引
- 标签驱动的数据检索

### FR-10: Dataset Pool数据集池
数据集管理和版本控制。
- 数据集池存储管理
- 数据集元数据管理
- 数据集质量评估
- 数据集版本控制
- 数据集导出/导入

### FR-11: CLI命令行工具
提供完整的命令行交互界面。
- 统一的CLI入口命令
- 子命令式工具调用
- 配置文件支持
- 输出格式化（JSON/YAML/表格）
- Shell补全支持

### FR-12: Python API与SDK
提供Python编程接口。
- 面向对象的API设计
- 类型注解完整
- 异常处理规范
- 异步/同步双模式
- 详细的API文档

## Non-Functional Requirements
- **NFR-1**: 安全性 - 核心加密算法强度不低于AES-256 / RSA-4096
- **NFR-2**: 性能 - 1MB数据加密耗时<1秒（混合加密模式）
- **NFR-3**: 可用性 - API设计简洁直观，5分钟上手
- **NFR-4**: 可扩展性 - 插件架构，新工具零侵入添加
- **NFR-5**: 可测试性 - 单元测试覆盖率>85%
- **NFR-6**: 文档完整性 - 每个工具都有使用文档和示例
- **NFR-7**: 跨平台 - 支持Linux/macOS/Windows

## Constraints
- **Technical**: Python 3.10+, cryptography, numpy, pydantic
- **Business**: 开源项目，MIT/Apache双许可
- **Dependencies**: 仅依赖成熟稳定的密码学库
- **合规性**: 遵守各国家和地区的密码学出口法规

## Assumptions
- "量子奇点"为经典计算模拟的数学模型
- JMKstudio/FBI/CIA等名称用于虚构的证书体系演示
- 几何证据加密基于经典数学，不涉及量子几何
- 用户具备基本的密码学知识

## Acceptance Criteria

### AC-1: 工具链核心架构
- **Given**: 已安装神誓工具链
- **When**: 注册新工具并通过工具链调用
- **Then**: 工具可被正确发现、加载和执行
- **Verification**: `programmatic`

### AC-2: KARMACA空间字典
- **Given**: 已初始化3维空间字典
- **When**: 使用空间字典加密并解密数据
- **Then**: 数据正确还原，空间映射具有确定性
- **Verification**: `programmatic`

### AC-3: 乾坤程序加密引擎
- **Given**: 配置了多级加密方案
- **When**: 执行乾坤加密流程
- **Then**: 数据按配置顺序经过所有加密层，可逆向解密
- **Verification**: `programmatic`

### AC-4: NLPTCmodel密钥生成
- **Given**: 输入一段中文文本
- **When**: 生成AES-256密钥
- **Then**: 相同文本生成相同密钥，密钥可用于加密
- **Verification**: `programmatic`

### AC-5: 奇点验证器
- **Given**: 密钥和对应的数据
- **When**: 执行奇点验证
- **Then**: 输出结构化验证报告，包含奇点特征和判定结果
- **Verification**: `programmatic`

### AC-6: 几何证据加密
- **Given**: 原始数据
- **When**: 生成几何证明并验证
- **Then**: 未篡改数据验证通过，篡改数据验证失败
- **Verification**: `programmatic`

### AC-7: 维度隐写
- **Given**: 载体数据和秘密信息
- **When**: 执行隐写后提取
- **Then**: 秘密信息正确还原，载体数据无明显统计异常
- **Verification**: `programmatic`

### AC-8: CA证书体系
- **Given**: JMKstudio根CA
- **When**: 签发三级证书链并验证
- **Then**: 证书链验证通过，特殊证书类型可识别
- **Verification**: `programmatic`

### AC-9: Karma标签系统
- **Given**: 数据集和标签配置
- **When**: 生成标签并签名验证
- **Then**: 标签格式正确，签名验证通过，可按标签检索
- **Verification**: `programmatic`

### AC-10: CLI工具
- **Given**: 命令行环境
- **When**: 执行oath命令及子命令
- **Then**: 命令正确执行，输出格式规范，帮助信息完整
- **Verification**: `programmatic`

### AC-11: Python API
- **Given**: Python开发环境
- **When**: 导入oath_toolchain包并调用API
- **Then**: API调用正常，返回值类型正确，异常处理规范
- **Verification**: `programmatic`
